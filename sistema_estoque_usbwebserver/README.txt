SISTEMA DE CONTROLE DE PRODUTOS — USBWEBSERVER

Versão adaptada para versões antigas do PHP.
1. Extraia esta pasta dentro da pasta root do USBWebserver.
2. Como seu banco estoque_produtos e a tabela produtos já existem, NÃO importe database.sql novamente.
3. Substitua index.php, config.php e style.css pelos arquivos desta versão.
4. Confira usuário e senha do MySQL no config.php.
5. Inicie o servidor web e MySQL e abra http://localhost:PORTA/sistema_estoque_usbwebserver/ usando a porta mostrada no USBWebserver.

O INSERT no database.sql é para instalação nova e deve ser executado apenas uma vez.
